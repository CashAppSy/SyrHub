# SyrHub — دليل التطبيقات السورية 🇸🇾

موقع بسيط وموحّد يجمع أبرز التطبيقات المحلية السورية، مصنّفة حسب النوع، مع روابط رسمية فقط. اسم الموقع والتطبيق: **SyrHub**.

🔗 **الموقع المباشر**: `https://YOUR_USERNAME.github.io/YOUR_REPO/` (بعد تفعيل GitHub Pages)

> ⚠️ **ملاحظة**: البيانات الحالية في `apps-data.js` (و`reviews-data.js` و`promotions-data.js`) هي **عينات تجريبية** لتوضيح الموقع أثناء التطوير. استبدلها بالتطبيقات الحقيقية الموثّقة قبل النشر (راجع التعليمات أعلى الملفات و`CONTRIBUTING.md`).

## المميزات

- 🌐 **ثنائي اللغة**: العربية (افتراضي) والإنجليزية مع زر تبديل في أعلى الموقع، والاتجاه RTL/LTR يتكيف تلقائيًا.
- 🌙 **وضع ليلي (Dark mode)**: زر تبديل في أعلى الموقع، يحترم تفضيل نظامك ويُحفظ اختيارك محليًا.
- 📊 **إحصائيات فورية**: عدد التطبيقات والفئات والتطبيقات الموثّقة والعروض النشطة.
- 🔍 **بحث وفرز**: بحث في الاسم والوصف باللغتين + فرز حسب التقييم أو الاسم، مع **ترتيب ذكي وفق الصلة** (تطابق الاسم أولًا) **وتمييز الكلمة المطابقة**.
- 📈 **تتبع Google Analytics** (قياس محسّن + أحداث مخصصة لتفاعلات الموقع).
- ⭐ **المفضلة وشوهد مؤخرًا**: حفظ التطبيقات المفضلة والاطلاع على آخر ما عاينته، وتُحفظ محليًا في متصفحك.
- 🧭 **صفحة تفاصيل لكل تطبيق**: روابط رسمية ومصادر التثبيت والآراء والعروض المرتبطة — مع رابط قابل للمشاركة عبر أي تطبيق (#/app/معرف-التطبيق).
- 📱 **شريط تنقل سفلي للموبايل**: رئيسية، بحث، عروض، مقارنة، والمزيد (مفضلة/لغة/سمة/مساهمة).
- ⚖️ **مقارنة التطبيقات**: اختر حتى 4 تطبيقات (زر ⇄) وقارن الفئة والتقييم والمنصات والروابط في جدول موحّد — مع شريط مقارنة سفلي وحفظ محلي.
- 📥 **نسخ الموقع APK / PWA**: صندوقان **بجانب بعضهما** في تذييل الصفحة (غير عائمين، لا يغطيان المحتوى) — صندوق "تطبيق أندرويد (APK)" يظهر لمستخدمي أندرويد فقط ويتّجه إلى الرابط في `APK_LINK`، وصندوق "نسخة PWA" يعرض تعليمات التثبيت؛ كلاهما يُخفى تلقائياً فقط عندما يكون المستخدم فعلاً داخل النسخة المثبّتة (نافذة PWA بأي نمط display أو WebView/ملف محلي لحزمة APK) ويظهر في المتصفح العادي دائماً.
- 🎨 **الشعار والأيقونات**: شعار الموقع `SyrHub-Icon.png` (favicon + `apple-touch-icon` + الرأس + الأغلفة الاجتماعية)، وأيقونة تثبيت تطبيق أندرويد والـ PWA هي `icons/App-SyrHub-Icon.png` (مُعرَّفة في `manifest.webmanifest` و`sw.js`).
- 🤝 **توصيات ذكية**: قسم "تطبيقات مشابهة" داخل صفحة التفاصيل يقترح تطبيقات من الفئة نفسها والمنصات المشتركة حسب التقييم.
- 🎟️ **كوبونات أسرع**: انسخ كود العرض بنقرة على الزر أو على الكود نفسه مع تأكيد مرئي وإعلان لقارئ الشاشة، ونسخ احتياطي للمتصفحات القديمة.
- 📣 **مشاركة وSEO ديناميكي**: عند فتح تطبيق تُحدَّث وسوم `title` و`og:` و`twitter:` تلقائياً باسم التطبيق ووصفه، وتُستعاد عند العودة للرئيسية، مع بيانات منظمة **JSON-LD** (`SoftwareApplication`/`WebSite`) تُحقن ديناميكياً لدعم الفهرسة.
- 🎛️ **فلاتر المنصات**: تصفية حسب المنصة (أندرويد/آيفون/ويب) و"موثّق فقط" — مطبَّقة مع البحث والفئات والفرز، وتُحفظ اختياراتك محلياً.
- 🕘 **آخر تحديث + الإبلاغ عن رابط معطّل**: صفحة التفاصيل تعرض "آخر تحديث" كلما توفر الحقل `lastUpdate`، وزر **"الإبلاغ عن رابط معطّل"** يفتح Issue جاهزاً على GitHub ببيانات التطبيق وروابطه.
- 🧭 **تنقّل بأزرار الرجوع**: كل تطبيق يصبح سجل تاريخ حقيقي (pushState) — رجوع/تقدم المتصفح يعملان بين التطبيقات، مع سجل "شاهدت مؤخرًا" وزر مسح السجل.
- 📲 **تثبيت كتطبيق PWA**: زر "تثبيت التطبيق" يظهر عند توفّر المتصفح لذلك، مع معرّف manifest واضح.
- ⚡ **أداء**: `content-visibility` للبطاقات، إزالة تأخير اللمس، وتباعد للبحث أثناء الكتابة، وتحميل كسول (`loading="lazy"`) لأيقونات التطبيقات عند توفر حقل `icon`.
- 📱 **PWA**: قابل للتثبيت على الهاتف ويعمل دون اتصال عبر Service Worker، مع **صفحة `offline.html`** مخصصة تُعرض عند انقطاع الشبكة بدلاً من صفحة مكررة، وألوان `theme-color`/`color-scheme` تتكيف مع الوضع الليلي/النهاري.
- 🗺️ **خريطة موقع `sitemap.xml`** تُولَّد تلقائياً من البيانات بواسطة أداة البناء.
- ♿ تحسينات إتاحة (Accessibility) وكروماتية متجاوبة.

## كيف يعمل الموقع

- صفحة واحدة (`index.html`) بدون أي حاجة لسيرفر أو قاعدة بيانات.
- **البيانات منفصلة عن الكود**: المصدر الحقيقي للبيانات ملفات JSON في [`data/`](./data) (`apps.json`، `categories.json`، `promotions.json`، `reviews.json`). عدّل أي ملف JSON ثم أعد التوليد:
  ```bash
  node build/build.js
  ```
  يولّد هذا الملف `apps-data.js` + `promotions-data.js` + `reviews-data.js` + `sitemap.xml`، مع فحص التكرارات والفئات والمنصات، وتنبيه عند بقاء روابط تجريبية (`example.com`).
- حقل `lastUpdate` (على صيغة `YYYY-MM` أو `YYYY-MM-DD`) يظهر كسطر "آخر تحديث" في صفحة التفاصيل، ويدخل في `sitemap.xml` كـ `lastmod` وفي الـ JSON-LD كـ `dateModified`.
- حقل `icon` الاختياري (رابط صورة) يعرض أيقونة التطبيق على البطاقة وفي التفاصيل بتحميل كسول بدلاً من أيقونة الفئة.
- العروض والكوبونات في [`promotions-data.js`](./promotions-data.js) — تظهر تلقائيًا فقط عند وجود عرض ساري، وتختفي بعد انتهاء صلاحيتها.
- آراء المستخدمين وتقييماتهم في [`reviews-data.js`](./reviews-data.js) — تقييم النجوم على كل تطبيق محسوب تلقائيًا كمعدّل لهذه الآراء.
- **لا يستضيف الموقع أي ملفات تثبيت (APK)** — كل تطبيق يُربط مباشرة بمصدره الرسمي (متجر Google Play / App Store / موقع الشركة). هذا لحماية المستخدمين من ملفات غير موثوقة ولتجنّب أي مسؤولية قانونية عن توزيع برمجيات لسنا الجهة المصدرة لها.

## كيف تقترح تطبيقًا

**الطريقة الأسهل (بدون حساب GitHub):**
📋 [عبّئ نموذج الاقتراح](GOOGLE_FORM_LINK_HERE) — سنراجعه ونضيفه بعد التحقق من الرابط الرسمي.

**الطريقة الثانية (عبر GitHub مباشرة):**
1. اعمل Fork للمستودع.
2. أضف بيانات التطبيق في `data/apps.json` حسب الصيغة الموضّحة داخل الملف (`apps-data.js` ملف مُولَّد).
3. افتح Pull Request.
4. سنراجع الطلب (نتحقق من الرابط الرسمي وصحة المعلومات) وندمجه إن كان مطابقًا للمعايير في [`CONTRIBUTING.md`](./CONTRIBUTING.md).

## التشغيل محليًا

لا يحتاج المشروع أي تثبيت، فقط افتح `index.html` في المتصفح، أو استخدم أي سيرفر بسيط:

```bash
python3 -m http.server 8000
```

ثم افتح `http://localhost:8000`.

## نشر الموقع على GitHub Pages

1. ادفع هذا المستودع إلى GitHub.
2. من إعدادات المستودع (Settings → Pages)، اختر Branch: `main` والمجلد `/root`.
3. سيصبح الموقع متاحًا خلال دقائق على الرابط الذي يظهر في نفس الصفحة.
